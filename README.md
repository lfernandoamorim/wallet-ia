# Wallet IA - Backend

Plataforma IA Backend desenvolvida com FastAPI, SQLAlchemy (asyncpg) e arquitetura em 3 camadas.

## Configuração do Ambiente

1. Certifique-se de ter o `uv` instalado.
2. Sincronize as dependências:
   ```bash
   uv sync
   ```
3. Execute os testes:
   ```bash
   uv run pytest
   ```
